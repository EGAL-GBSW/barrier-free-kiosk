# 대화형 AI 음성 주문

- 백엔드 환경: `AI_ORDER_BASE_URL`에 백엔드에서 접근 가능한 AI 주문 서버 주소를 설정합니다.
- 프론트 환경: `VITE_VOICE_MODE=ai`. 서버를 재시작하고 Chrome에서 마이크를 허용합니다.
- AI 주문 서버 환경: `BACKEND_BASE_URL`에 AI 서버에서 접속 가능한 백엔드 기본 주소를 설정합니다. 예를 들어 이 맥에서 Swagger가 SSH 터널을 통해 `http://127.0.0.1:3300/docs/`로 열린다면 이 맥에서 실행하는 AI 서버에는 `BACKEND_BASE_URL=http://127.0.0.1:3300`을 사용합니다. AI 서버가 다른 컴퓨터에서 실행되면 그 컴퓨터에서 도달 가능한 주소로 바꿔야 합니다. 기존 `MENU_API_URL`이 설정되어 있으면 해당 전체 메뉴 URL이 우선합니다.

Swagger는 `GET /menus`, `POST /orders/quote`, `POST /voice/analyze`를 제공합니다. 프론트는 백엔드에 `session_id`와 텍스트를 보내고, 백엔드는 설정된 AI 주소의 `/ai/order/text`로 중계합니다. 백엔드의 `AI_ORDER_BASE_URL`이 비어 있으면 `/voice/analyze`는 503을 반환하므로 백엔드 실행 환경에 설정하고 재시작해야 합니다. 백엔드가 원격 서버라면 맥의 `127.0.0.1` 주소를 그대로 사용할 수 없습니다. 같은 내부 서버에 AI를 배포하거나 안전한 사설 연결이 필요합니다. AI 서버에는 별도 인증이 없으므로 직접 인터넷에 공개하지 않습니다.

1. 포장 또는 매장 선택 후 **음성 주문**을 누릅니다.
2. “아이스 아메리카노 두 잔 주세요”라고 말합니다. AI가 사이즈나 샷을 물으면 읽기가 끝난 뒤 답합니다. 예: “보통 사이즈요”, “샷 추가 안 할게요”.
3. “결제해 주세요”라고 말합니다. AI가 주문 준비를 확인하면 기존 주문 API가 메뉴와 금액을 계산하고 화면과 음성으로 안내합니다.
4. 안내가 끝난 뒤 “네, 주문할게요”라고 말하거나 **주문 확정**을 누릅니다. 일반 시연 모드는 주문을 저장합니다. 토스 테스트 모드는 결제 화면으로 이동하고 기존 결제 단계에서 사용자가 결제를 진행합니다.
5. 확인 전에 “결제 취소해 주세요” 또는 “아메리카노 취소해 주세요”라고 말하면 같은 AI 세션으로 전달됩니다. 결제 취소는 아직 승인된 결제의 환불이 아니라 견적 확인 취소입니다.

Web Speech가 만든 텍스트만 `POST /voice/analyze`로 보내고, Express가 팀 AI의 `POST /ai/order/text`로 같은 `session_id`를 전달합니다. 음성 안내를 읽는 동안 마이크 인식을 멈춥니다. 인식이 실패하거나 TTS가 지원되지 않으면 음성 주문을 다시 누르거나 터치 주문을 선택할 수 있습니다. 터치로 전환하면 미확정 음성 세션은 종료되고 기존 터치 장바구니는 유지됩니다.

AI 서버는 메뉴 이름·설명에 명시된 취향 표현과 분류·가격·온도를 사용하여 후보를 좁힙니다. 조건은 해당 음성 주문 세션에 누적되며, 후보 이름을 `message`에 포함하므로 화면과 TTS로 함께 안내합니다. 사용자가 특정 메뉴를 고르면 기존 수량·옵션 재질문 및 결제 요청 흐름으로 이어집니다. `MENU_API_URL`이 설정된 경우 백엔드 메뉴를 매 발화마다 읽고, 설정되지 않았다면 저장된 스냅샷을 사용합니다. 카페인·알레르기 같은 성분은 현재 메뉴에 확인된 정보가 없어 추측하지 않습니다.

TTS는 브라우저에서 사용 가능한 한국어 음성을 우선하고 안내 속도를 조금 낮춥니다. 음질과 실제 음성 종류는 기기와 브라우저에 따라 달라집니다. TTS가 없거나 재생에 실패하면 질문을 화면에 남기고 다시 말하기 버튼을 표시합니다. 실제 마이크·스피커 테스트 시 재질문을 끝까지 읽은 뒤 답변을 듣는지 확인하세요.

`request_quote`는 주문 저장 신호가 아닙니다. 백엔드의 `POST /orders/quote`만 호출합니다. 이미 담은 터치 주문이 있으면 함께 계산하며, 견적을 본 뒤 그 장바구니가 바뀌면 다시 견적을 받아야 합니다.
