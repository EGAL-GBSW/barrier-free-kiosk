# 대화형 AI 음성 주문

- 백엔드 환경: `AI_ORDER_BASE_URL=http://172.28.12.191:8000` (팀원의 실제 주문 API 주소).
- 프론트 환경: `VITE_VOICE_MODE=ai`. 서버를 재시작하고 Chrome에서 마이크를 허용합니다.

1. 포장 또는 매장 선택 후 **음성 주문**을 누릅니다.
2. “아이스 아메리카노 두 잔 주세요”라고 말합니다. AI가 사이즈나 샷을 물으면 읽기가 끝난 뒤 답합니다. 예: “보통 사이즈요”, “샷 추가 안 할게요”.
3. “결제해 주세요”라고 말합니다. AI가 주문 준비를 확인하면 기존 주문 API가 메뉴와 금액을 계산하고 화면과 음성으로 안내합니다.
4. 안내가 끝난 뒤 “네, 주문할게요”라고 말하거나 **주문 확정**을 누릅니다. 일반 시연 모드는 주문을 저장합니다. 토스 테스트 모드는 결제 화면으로 이동하고 기존 결제 단계에서 사용자가 결제를 진행합니다.
5. 확인 전에 “결제 취소해 주세요” 또는 “아메리카노 취소해 주세요”라고 말하면 같은 AI 세션으로 전달됩니다. 결제 취소는 아직 승인된 결제의 환불이 아니라 견적 확인 취소입니다.

Web Speech가 만든 텍스트만 `POST /voice/analyze`로 보내고, Express가 팀 AI의 `POST /ai/order/text`로 같은 `session_id`를 전달합니다. 음성 안내를 읽는 동안 마이크 인식을 멈춥니다. 인식이 실패하거나 TTS가 지원되지 않으면 음성 주문을 다시 누르거나 터치 주문을 선택할 수 있습니다. 터치로 전환하면 미확정 음성 세션은 종료되고 기존 터치 장바구니는 유지됩니다.

`request_quote`는 주문 저장 신호가 아닙니다. 백엔드의 `POST /orders/quote`만 호출합니다. 이미 담은 터치 주문이 있으면 함께 계산하며, 견적을 본 뒤 그 장바구니가 바뀌면 다시 견적을 받아야 합니다.
